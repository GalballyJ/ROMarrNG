The interface now offers twelve selectable languages with translated navigation, settings, help, validation, and app-owned statuses. Arabic labels use right-to-left direction metadata inside the left-to-right shell; full RTL support remains unreviewed. Date and number formatting stays separate, and game titles, platform names, paths, API responses, and other user data remain unchanged.
